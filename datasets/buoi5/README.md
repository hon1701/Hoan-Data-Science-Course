# Dữ liệu thực hành Buổi 5

- `state/`: bản sao dữ liệu US States từ [jakevdp/data-USstates](https://github.com/jakevdp/data-USstates), dùng trong ví dụ `03.07-Merge-and-Join.ipynb` của *Python Data Science Handbook*.
- `babynames_sample/`: mẫu nhỏ, nguyên giá trị từ bốn file `yob1980.txt`, `yob1990.txt`, `yob2000.txt`, `yob2010.txt` trong [davidrpugh/python-for-data-analysis](https://github.com/davidrpugh/python-for-data-analysis/tree/master/datasets/babynames). Mẫu chỉ gồm một số tên nữ để notebook chạy nhanh và minh họa `concat`, `MultiIndex`, `unstack` và dữ liệu thiếu.

Các file mẫu không đại diện cho toàn bộ phân bố tên trẻ em Hoa Kỳ.
